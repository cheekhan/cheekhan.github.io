# 三才

**核心定义：**
::: info 周易・说卦传
昔者圣人之作《易》也，将以顺性命之理。是以立天之道曰阴与阳，立地之道曰柔与刚，立人之道曰仁与义。兼三才而两之，故《易》六画而成卦。
::: 
三才即天、地、人三者，三才之理就是天地人同源同构、分工协同、感应互通、人为主枢的宇宙运行总规律。

**天道**

天道，以阴阳为纲，主施化，为万物之动力。

是宇宙运行的总规律、万物生发的本源动力，核心是阴阳二气的消长流转。

天道的核心特质是 “施”，主动、无形、统摄、周流不息，为万物赋予生命的本源动力。

**地道**

地道，以刚柔为体，主承载，为万物之根基。

是大地承载化育的法则、有形万物的成型规律，核心是五行刚柔的生克制化。

地道的核心特质是 “承”，被动、有形、承载、稳定厚重，为万物提供生长的实体根基。

**人道**
人道，有独特的文化内涵，是三才到枢纽，在天地之间，起到参与和调节的作用。

人道的核心特质是 “通”，兼具阴阳、统摄刚柔，是唯一能主动认知天道、顺应地道、调整自身行为，进而反哺天地的存在，是三才体系中动静转换、天人互通的关键。
