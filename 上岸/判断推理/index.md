# 判断推理

行测提分空间最大的模块，方法性最强，练熟规则比刷题量更重要。

## 一、图形推理

- 位置：平移、旋转、翻转
- 样式：叠加、相减、求同、求异、遍历
- 属性：对称性、曲直性、开闭性
- 数量：点、线、面、角、素
- 空间重构：相对面、相邻面、箭头法、时针法

**思考顺序**：先看图形是否相似（位置、样式），再看是否杂乱（属性、数量），最后考虑空间与特殊规律。

## 二、定义判断

拆关键词：主体、客体、条件、方式、目的、结果。逐项匹配，不需要背景知识，警惕"偷换主体""以偏概全"。

## 三、类比推理

- 语义关系：近义、反义、比喻、象征
- 逻辑关系：全同、包含、交叉、并列、因果、条件
- 语法关系：主谓、动宾、偏正、并列

**做题顺序**：先看语义，再看逻辑，最后看语法；选不出唯一答案时用纵向比较。

## 四、逻辑判断

**翻译推理**

- 充分条件：如果 A 那么 B，记作 A → B
- 必要条件：只有 A 才 B，记作 B → A
- 逆否等价：A → B 等价于 ¬B → ¬A
- 递推：A → B，B → C，可得 A → C

**真假推理**：找矛盾关系（必有一真一假）与反对关系，再结合题干条件。

**分析推理**：列表、排除、假设，条件多的题先整理信息。

**加强削弱**

1. 找论点与论据
2. 判断方式：搭桥、拆桥、补充论据、举反例
3. 比较力度：直接强于间接，必然强于可能

**原因解释**：兼顾矛盾双方，给出能同时解释现象的选项。
