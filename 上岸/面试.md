# 面试

笔试之后的第二道关。评分看内容，也看表达、状态与时间控制。

## 一、常见形式

- **结构化面试**：同一岗位同一套题，逐题作答
- **无领导小组讨论**：给定材料讨论，考官观察角色与贡献
- **结构化小组**：答题 + 点评 + 回应

以本省公告为准，不同形式准备重点不同。

## 二、结构化题型与框架

**综合分析**

- 现象类：表明态度 → 分析原因与影响 → 提出对策
- 观点类：解释含义 → 辩证分析 → 落到行动

**计划组织协调**

事前：明确目的、对象、时间地点、人员分工、物资与预案
事中：按环节推进，突出重点动作
事后：总结成果、形成材料、建立长效机制

**人际关系**

先摆正心态，再找原因（沟通不畅、职责不清、理解偏差），最后给具体做法。不推责、不越权。

**应急应变**

1. 稳定局面，控制事态
2. 分清轻重缓急，先急后缓
3. 解决当前问题
4. 复盘与预防

**言语表达 / 情景模拟**

先明确身份与对象，再进入情境说话，语气要符合场景，避免念稿感。

**岗位匹配**

结合经历讲动机，用具体事例证明能力，避免空泛表态。

## 三、表达训练

- 用逻辑词串联：第一、第二、第三；一方面、另一方面
- 每道题控制在 3 分钟左右，先练结构再练内容
- 录音复盘：听口头禅、语速、停顿、重复
- 眼神与坐姿：看考官、少低头、手势自然

## 四、备考方法

1. 按题型各练 10 道，形成自己的答题模板
2. 积累本地案例与岗位相关知识
3. 全真模拟：抽题、计时、录像、复盘
4. 考前保持开口，每天至少 3 题
