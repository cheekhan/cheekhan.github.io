# 写作

对应申论与公文写作。核心不是文采，而是从材料中找点、按要求组织答案。

## 一、作答步骤

1. **审题**：看清作答对象、范围、身份、字数、题目数量
2. **找点**：回到限定材料，按段落提取关键词与要点
3. **加工**：合并同类项，按逻辑分类，提炼小标题
4. **书写**：分条作答，序号清楚，字迹工整

评分通常按点给分：要点全、表述准、结构清，比语言华丽更重要。

## 二、归纳概括

- 问什么答什么，不做延伸
- 要点来源：材料原词优先，其次同义替换
- 呈现形式：`序号 + 核心词 + 具体说明`
- 常见失分：漏点、要点重复、把分析写成概括

## 三、综合分析

常见问法：谈谈对某句话、某个现象的理解。

**作答结构**

1. 解释含义：这句话在说什么
2. 分析原因或影响：多角度展开（主观客观、积极消极）
3. 得出结论或对策：回到材料立场

## 四、提出对策

- 先找材料中的问题与原因，对策要能对应问题
- 对策来源：材料直接给、从问题反推、从经验补充
- 一条对策写清：主体 + 做法 + 目的
- 避免空话，比如只写"加强管理"，不写怎么管

## 五、贯彻执行（应用文）

**格式要素**：标题、称谓、正文、落款、日期，按文种取舍。

| 文种 | 要点 |
| --- | --- |
| 倡议书 | 背景 + 倡议内容 + 号召 |
| 建议书 | 问题 + 建议 + 期望 |
| 汇报 / 总结 | 情况 + 做法 + 成效 + 问题 + 下一步 |
| 讲话稿 | 开场 + 主体分层 + 收尾 |
| 短评 / 编者按 | 观点鲜明，短小有力 |

注意身份与对象：写给谁、以谁的口吻写，决定语气与内容边界。

## 六、申发论述（大作文）

**结构**

- 标题：点明主题，可用对仗或动宾结构
- 开头：引材料 + 亮明总论点
- 主体：3 个左右分论点，段落内用"论点 + 阐释 + 例证 + 回扣"
- 结尾：总结 + 升华，不喊空口号

**分论点写法**：从材料中提炼，彼此并列或递进，避免交叉重复。

## 七、素材积累

- 规范表述：把口语化表达替换为书面表达
- 案例：每类主题准备两三个，能用一句话讲清
- 金句：少量即可，重点是逻辑与要点
