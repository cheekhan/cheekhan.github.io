# 上岸

考公（公务员录用考试）知识点整理。以本省公告和考试大纲为准，这里只沉淀可复用的方法、公式与答题框架。

## 一、考试构成

| 阶段 | 内容 | 说明 |
| --- | --- | --- |
| 笔试 | 行政职业能力测验（行测） | 客观题，模块固定 |
| 笔试 | 申论 | 主观题，分类命卷 |
| 笔试 | 专业科目 | 部分岗位加考，如公安、法律、财会 |
| 面试 | 结构化 / 无领导 / 结构化小组 | 以公告为准 |
| 后续 | 体检、考察、公示 | 环节性淘汰 |

行测与申论通常各占笔试总成绩的一半，具体折算比例看本省公告。

## 二、备考主线

1. **摸底**：整套真题限时做一遍，记录各模块正确率与耗时。
2. **打基础**：按模块学方法，先听课或看教材，再做专项题。
3. **刷专项**：以正确率为目标，弱项多投入，强项只保手感。
4. **套卷训练**：严格计时，固定做题顺序，练取舍。
5. **冲刺**：真题复盘为主，错题重做，控制新题数量。

## 四、复盘记录

每套卷子建议记录：

- 各模块用时与正确率
- 错题原因：不会、看错、算错、超时
- 可迁移的结论：哪类题该放弃、哪类题必须拿分
